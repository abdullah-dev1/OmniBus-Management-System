# Overview

**OmniBus Management System** is a database-driven application developed to streamline the management of bus transportation services through centralized data management and automated operational workflows.

The system provides an integrated platform for managing passengers, buses, routes, schedules, reservations, ticketing, payments, and administrative operations. Built around a relational database architecture, it emphasizes data consistency, efficient transaction processing, and structured information management.

The project demonstrates practical implementation of database design principles, SQL programming, PL/SQL procedures, and GUI integration within a real-world transportation management scenario.

---

# Project Objectives

The primary objectives of the system are:

- Centralize transportation data management
- Automate ticket booking operations
- Manage routes and trip schedules efficiently
- Maintain passenger and staff records
- Process ticket payments
- Demonstrate relational database design and implementation

# System Architecture

The application follows a layered architecture that separates user interaction, business logic, and database operations.

```text
                User Interface
                      │
                      ▼
              Application Layer
                      │
                      ▼
             Business Logic Layer
                      │
                      ▼
         Oracle Database (SQL / PL-SQL)
```

This architecture promotes maintainability, modularity, and clear separation of responsibilities between the application and database components.

---

# Database Design

The system is built upon a relational database model designed to ensure data integrity, normalization, and efficient query execution.

The database includes entities representing:

- Passengers
- Staff
- Buses
- Routes
- Trips
- Reservations
- Tickets
- Payments

Entity relationships were modeled using an **Enhanced Entity Relationship Diagram (EERD)** before implementation.

# Getting Started

## Database Setup

Execute the database script:

```bash
Omni-Bus-Management.sql
```

This script creates the required database schema, tables, relationships, constraints, stored procedures, and supporting database objects.

---

## Launch the Application

After configuring the database connection, start the Python GUI application.

The application communicates directly with the Oracle database to perform all transactional operations.
