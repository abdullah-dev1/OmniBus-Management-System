# OmniBus Management System

Database Systems Lab Semester Project

## Project Description
OmniBus Management System is a database-driven application for managing bus transportation services including booking, payment, ticket generation, routes, buses, and staff management.

## Features
- Passenger registration/login
- Trip scheduling
- Ticket booking
- Payment processing
- Staff management
- Dashboard analytics

## Technologies Used
- Oracle SQL / PL-SQL
- Python / GUI
- Database Design (ERD/EERD)

## Setup Instructions
1. Run 03_DDL.sql
2. Run 04_DML_Inserts.sql
3. Run 06_PLSQL.sql
4. Launch GUI project
